# NetworkMonitor

A full-stack network diagnostic and monitoring application built with React and Spring Boot.

## Features

- DNS resolution
- Network reachability and packet-loss checks
- TCP port checks (22, 53, 80, 443)
- HTTP/HTTPS connectivity checks
- Local network interface information
- Continuous network monitoring
- Diagnostic history
- Performance chart
- Concurrent network diagnostics

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- Chart.js

### Backend
- Java 17
- Spring Boot
- Maven
